# Vendored frontend assets

All assets are served locally through `go:embed`; there is no CDN and no
runtime npm/Node dependency. Versions are pinned and hashes are recorded
below. Verify with `sha256sum` after any upgrade.

The compatibility floor is Windows XP-era browsers (Pale Moon 28, Basilisk
55, K-Meleon 74G/76, Firefox 52 ESR). JavaScript is authored in modern
syntax under `frontend/src` and bundled to `target=firefox52` by esbuild
(see `Earthfile +frontend`); the compatibility polyfills live in
`frontend/src/compat.js`.

`ui.js` is generated by esbuild from `frontend/src` and is not committed.

The Alpine CSP build does not auto-start; the `ui.js` bundle registers
components on `alpine:init` and calls `Alpine.start()`. The CSP build
disables `x-html` and keeps the strict Content-Security-Policy intact.
